How you used GitHub Copilot (example prompts or situations).
    I used github Copilot for a massive overhaul of my app to add a large number of accessability features, user features, and the chart. For exampel I used an edit prompt and added in a list of features that I wanted to add, and then had copilot go through and complete the first overhaul to add the new dashboard layout versus the old hamburger one that I had added on my own, and it added in general streamlining features so that each filter closes and every field resets when needed and essentially fixed minor bugs within the code that might have caused errors later in time. Another example is when I decided to remove ScrollView because it was throwing errors and I didnt want to download another library, so I used copilot to simply edit the syntax and remove scrollview from the entire project. I did this several times, and although it might have been simmpler and faster to add the library, I was having fun. Another example would be when I used the chat feature to check my code for existing errors and the scrollview syntax. 
At least one suggestion Copilot gave that you changed or rejected, and why.
    Copilot tried to add more filters that already existed, and modify said filters once I suggested the removal. This was for the date filter on the dashboard, and when I added the dashboard physically, copilot also added a date filter that was a preset filter for week day and month, versus my day filter of similar design and slightly less efficiency. I removed it becausee I preferred how my addition looked. 
One example where Copilot saved you time or effort.
    There are many examples of where copilot saved me time and effort when I was redesigning my app, and the greatest example was when I added a bulk order of features including the redesigned dashboard design I mentioned before. It added the light mode, the currency feature, the seperate dashboard, the new filter, the modified chart, the animations which were eventually removed and organizational differences for the code, which would have taken many hours if not several days to complete took a half hour to generate and then edit to fit in my style.
